# COE201 — Large Language Models

Coursework for **COE201 Large Language Models**, covering the full LLM pipeline from fundamentals to production deployment.

## Contents

### Assignments

| # | Topic |
|---|---|
| 1 | Tokenization and embeddings |
| 2 | Transformer architecture implementation |
| 4 | LLM evaluation and benchmarking |

### Labs

| # | Topic | Description |
|---|---|---|
| 1 | Python Fundamentals | NumPy, PyTorch basics |
| 2 | PyTorch | Automatic differentiation, MLPs, custom autograd |
| 3 | Preprocessing | Tokenization, batching, data pipelines |
| 4 | RNN | Recurrent neural networks from scratch |
| 5 | Transformer (Part 1) | Self-attention and multi-head attention |
| 6 | Transformer (Part 2) | Full encoder-decoder implementation |
| 7 | HuggingFace | Using pretrained models and tokenizers |
| 8 | Infrastructure | GPU training, mixed precision, distributed |
| 9 | LoRA Fine-tuning | Parameter-efficient fine-tuning |
| 10 | Quantization | INT8/INT4 quantization for deployment |
| 11 | RAG | Retrieval-augmented generation |
| 12 | Agents | Tool-use and autonomous LLM agents |
| 13 | VLMs | Vision-language models |

## Quick Start

Each lab is self-contained. Install dependencies:

```bash
pip install -r requirements.txt  # if provided
```

Or run Jupyter notebooks directly:

```bash
jupyter lab
```

## Topics Covered

- Transformer architecture (attention, positional encoding, layer norm)
- Pre-training and fine-tuning paradigms
- Parameter-efficient adaptation (LoRA, adapters)
- Model compression (quantization, pruning)
- Retrieval-augmented generation (RAG)
- LLM agents and tool use
- Multimodal models (VLMs)
- Production deployment considerations
